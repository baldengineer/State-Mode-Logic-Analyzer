## DAC Test Board
This board is to test current drive capability of a [Microchip MCP7425](https://www.microchip.com/en-us/product/mcp4725) 12-bit DAC. It drives the Vcc of the dual-supply buffer. The idea is to use this DAC to vary the VCC to vary the Vthreshold.
